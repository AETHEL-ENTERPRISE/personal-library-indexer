PERSONAL LIBRARY INDEXER

1. Extract the ZIP completely.
2. Install Python 3.10 or newer from https://www.python.org/downloads/
   Python 3.12 is recommended. Include Tcl/Tk and Add Python to PATH.
3. Double-click start_windows.bat.
   First setup needs Internet to install the PDF-reading dependency.
4. Click Try sample books. Expected result: 6 books, 3 PDF, 3 EPUB.
5. Search for python, or filter by genre / format, then export a CSV.
