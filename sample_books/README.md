# Original demo collection

These are short, original demonstration documents created for this project. They are not full commercial books. The original text is distributed under the repository's MIT license.

| Book | Format | Expected genre |
| --- | --- | --- |
| Python for Curious Minds | PDF | Technology |
| An Introduction to Space | PDF | Science |
| Small Business Basics | PDF | Business |
| The Clockmaker's Secret | EPUB | Fiction |
| Cities Through Time | EPUB | History |
| Better Study Habits | EPUB | Self-help |

All samples use **Demo Library** as the author. The business PDF is in `reference/` to demonstrate recursive scanning. EPUB samples have no fixed page count.

Regenerate the files with `python tools/make_sample_books.py` from the project root after installing the optional `reportlab` package.
